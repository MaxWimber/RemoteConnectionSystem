# Дорожная карта

Текущая фаза: первая, у которой не закрыт `Gate`. Фаза закрывается только проверкой на реальном сервере по логам
пользователя. Если пункт выполнить не удалось, он остаётся незакрытым, а причина и замеры записываются в раздел
«Заметки» фазы.

Разработка идёт на ПК разработки, проверка на сервере выполняется по циклу из [TESTING.md](TESTING.md).
Каждый пункт `Gate` помечен: **[ПК]** проверяется здесь, **[сервер]** подтверждается логами с сервера.

## Итоговая проверка

Выполняется с Android через мобильный интернет и с ноутбука вне домашней сети.

3. Запуск программы и игры: мышь, клавиатура, физический и экранный геймпад, касания.
4. Загрузка и скачивание большого файла с обрывом, докачкой и совпадением SHA-256.
5. Блокировка экрана, UAC и перезагрузка: после неё можно войти в Windows удалённо.
6. Два часа игры без падений и утечек памяти.
