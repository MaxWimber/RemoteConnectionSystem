Текущая фаза: первая, у которой не закрыт `Gate`. Фаза закрывается только проверкой на реальном сервере по логам
пользователя. Если пункт выполнить не удалось, он остаётся незакрытым, а причина и замеры записываются в раздел
«Заметки» фазы.

Разработка идёт на ПК разработки, проверка на сервере выполняется по циклу из [TESTING.md](TESTING.md).
Каждый пункт `Gate` помечен: **[ПК]** проверяется здесь, **[сервер]** подтверждается логами с сервера.
