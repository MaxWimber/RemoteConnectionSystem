# Подготовка сервера

Этот чек-лист выполняете вы. Он содержит действия, которые требуют физического доступа, панелей управления
или подтверждения владельца. Разработка идёт на другом ПК, а сервер только запускает готовые пакеты: порядок описан
в [TESTING.md](TESTING.md).

## 1. Железо

- [ ] Подключите монитор или HDMI-заглушку **к RX 560**. Без дисплея захват работать не будет.
- [ ] Подключите плату удалённого включения к разъёму кнопки питания. Её настройка не зависит от этой системы.
- [ ] Подключите сервер к роутеру кабелем.

## 2. BIOS

- [ ] Включите автоматический запуск после потери питания: обычно `Restore after AC Power Loss = Power On`.
- [ ] Основным графическим адаптером выберите PEG, то есть RX 560.
- [ ] Если плате включения нужно, отключите ErP.
- [ ] Включите XMP или профиль памяти, если он доступен.

## 3. Windows

- [ ] Установите обновления и актуальный драйвер RX 560 с сайта AMD.
- [ ] Запретите сон и гибернацию при питании от сети.
- [ ] Автоматический вход в Windows не настраивайте: после фазы 6 экран входа будет доступен удалённо.
- [ ] Шифрование диска необязательно. Если включаете BitLocker, не используйте PIN при запуске: удалённо его ввести нельзя.
- [ ] Создайте папку `D:\RCS-Storage`. Том `D:` не защищён от отказа диска, поэтому важные файлы храните ещё и в другом месте.

## 4. Инструменты

С 4 ноября 2026 года разработка идёт на сервере (D-015). В PowerShell **от имени администратора**:

```powershell
winget install --id Git.Git -e
winget install --id Rustlang.Rustup -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Microsoft.VisualStudio.2022.BuildTools -e --override "--quiet --wait --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

Build Tools ставятся долго, 10–20 минут. После установки откройте новое окно PowerShell, чтобы обновились пути.
Версию Rust и компоненты `clippy`, `rustfmt` при первом запуске `cargo` подтянет `rust-toolchain.toml`.

Проект лежит в `C:\RCS\src`, пакеты и их логи в `C:\RCS`. Claude Code работает в приложении Claude, вкладка Code,
в папке `C:\RCS\src`.

## 5. Роутер

- [ ] Закрепите за сервером постоянный локальный IP `192.168.1.12` (DHCP-резервация по MAC).
- [ ] Пробросьте на этот IP порты `80/TCP` и `8444/TCP`. Внешний и внутренний порт в каждом правиле одинаковы. Внешний `443/TCP` на этом подключении закрыт.
- [ ] Пока **не** включайте постоянный проброс `8443/UDP`. Он нужен на время проверки в фазе 0 и окончательно только после фазы 3.
- [ ] Выключите UPnP, если он не нужен другим устройствам.
- [ ] Смените пароль администратора роутера, если он заводской.
- [ ] Не включайте DMZ для сервера.

## 6. Домен

Домен сейчас обслуживается DNS Timeweb, A-запись указывает на `109.71.242.204`. HTTP-запрос к домену при
проверке 2 ноября 2026 года не получил ответа за 15 секунд. AAAA-записи нет. Почта настроена отдельно:
MX `mx1.timeweb.ru` и `mx2.timeweb.ru`, TXT с SPF. Смена A-записи её не затрагивает, если MX и TXT не менять.

**Перед изменениями проверьте:** нет ли на текущем адресе сайта, который вам нужен.

Затем в панели Timeweb:

- [ ] Измените только A-запись `maxwimber.ru` на белый IP сервера. MX и TXT оставьте как есть.
- [ ] Подождите обновления DNS.

Проверка с любого компьютера:

```powershell
Resolve-DnsName maxwimber.ru -Type A
```

## 7. Проверка UDP в фазе 0

Пакет фазы 0 запустит на сервере слушатель, а вы временно включите проброс `8443/UDP`. Для отправки нужен компьютер
**вне домашней сети**. Подойдёт ПК разработки, если его сеть выпускает UDP наружу, либо ноутбук на мобильном интернете.
Когда на сервере появится надпись об ожидании пакета, выполните на нём, подставив внешний IP. Команда отправит
пять пакетов, потому что один UDP-пакет может потеряться:

```powershell
$u = New-Object System.Net.Sockets.UdpClient; $b = [Text.Encoding]::ASCII.GetBytes('rcs-test'); for ($i = 0; $i -lt 5; $i++) { [void]$u.Send($b, $b.Length, 'ВНЕШНИЙ_IP', 8443); Start-Sleep -Seconds 1 }; $u.Close()
```

После успешной проверки снова выключите проброс `8443/UDP`.

## Дальше

3. Фаза 3 обязательно завершается до постоянного открытия `8443/UDP`.
